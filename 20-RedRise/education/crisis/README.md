# Crisis Support – Help Is Available

If you are in immediate danger, call **112** now.

---

## Emergency Numbers (South Africa)

| Service | Number |
| :--- | :--- |
| **Emergency (any service, from cell phone)** | **112** |
| Ambulance (landline) | 10177 |
